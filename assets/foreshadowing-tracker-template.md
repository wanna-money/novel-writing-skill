# 伏笔追踪表模板

> 管理所有伏笔的生命周期——从埋入到回收，防止遗忘或前后矛盾。

---

## 使用说明

1. 每埋入一个伏笔，立即在此表中登记
2. 每次写新章节前，检查是否有本章应该回收的伏笔
3. 每5章做一次全表审查，检查是否有遗忘的伏笔
4. 伏笔ID格式：F-001, F-002, ...（按埋入顺序编号）
