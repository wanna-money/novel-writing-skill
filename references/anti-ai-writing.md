# 防AI化写作手法详解

> 让AI写出来的文字不像AI——七大禁令、替代技法、各题材的语言风格指南。

---

## 一、AI文风的七大特征（必须规避）

AI生成的文字有明显的"机器味"，主要表现为以下七种特征。每写一段都要检查是否踩中：

### 特征一：空洞形容词堆砌

```
AI味：
  "他感到一种深深的、无法言喻的悲伤涌上心头"
  "她的眼中闪烁着坚定而复杂的光芒"
  "一种难以名状的恐惧笼罩了整个空间"

人味：
  "他蹲下来，把脸埋进膝盖里，肩膀一抖一抖的，但没出声"
  "她看了他一眼，把手里的伞递过去，转身走了"
  "他发现自己的手在抖，握了两次才握住门把手"
```

**替代技法**：用具体的动作、感官细节、身体反应来替代抽象的情感形容词。人在极端情绪下不会"感到悲伤"，他会蹲下来、会发抖、会突然很想吃东西、会对着墙发呆。

### 特征二：万能连接词

```
AI味：
  "然而，他并没有放弃。此外，他还发现了……
   与此同时，另一边的战况也……
   值得注意的是，这个发现意味着……"

人味：
  （直接切换场景，不需要连接词）
  （用角色的动作过渡：他转过身，看见——）
  （用对话过渡："你听说了吗？"）
```

**替代技法**：
- 场景切换：直接空一行，换一个场景
- 动作过渡：角色做了一个动作，视线转向，进入下一个画面
- 对话过渡：一句对话自然引出下一段内容
- 时间跳跃："三天后"、"等他再睁开眼"
- 感官过渡：一个声音、一种气味将注意力从A拉到B

### 特征三：总结式叙事

```
AI味：
  "经过一番激烈的战斗，他终于获得了胜利。
   这场战斗让他明白了团队合作的重要性。"

人味：
  （完整写出战斗过程的关键节点）
  （不要写"他明白了"——让读者自己明白）
```

**替代技法**：永远写过程，不写结论。读者不需要你告诉他"这场战斗很激烈"——如果你把战斗写好了，他自然感受到。

### 特征四：均匀节奏

AI生成的文字有一种恼人的"均匀感"——每段差不多长，每句差不多结构，语气始终保持同一水平。

```
AI味（每段3-4行，每句15-20字，结构相似）：
  "他向前走了几步，仔细观察着周围的环境。
   空气中弥漫着一股奇怪的味道，让他感到不安。
   远处传来了一些声响，他不由得加快了脚步。
   终于，他来到了那个传说中的地方。"

人味（长短交替，节奏起伏）：
  "他走。
   路两边是烧过的房子，黑墙上还能看到木炭的纹路，
   歪歪扭扭的，像小孩子画的树枝。空气里全是灰。
   他走了很久。
   脚底踩到一个软的东西。他没低头看。"
```

**替代技法**：
- 紧张时用短句，甚至一个词单独成段
- 铺垫时用长句，让节奏慢下来
- 刻意制造"不均匀"——突然一个超短的句子打破节奏
- 用标点符号控制节奏：省略号制造迟疑，破折号制造突转

### 特征五：情感直述

```
AI味：
  "她感到非常伤心。"
  "他内心充满了愤怒。"
  "这让她感到既惊讶又害怕。"

人味：
  "她把碗放到桌上，慢慢坐下来，盯着碗里的汤看了很久。"
  "他'啪'地把杯子摔了。然后蹲下来，一块一块捡碎片。"
  "她嘴角抽了一下，说'哦'。又说了一个'哦'。"
```

**替代技法**——情感表达的四层阶梯：

| 层级 | 技法 | 示例 |
|------|------|------|
| 第一层：身体反应 | 写生理变化 | "他的胃缩了一下" |
| 第二层：微动作 | 写无意识的小动作 | "她把袖口拉到手掌里捏着" |
| 第三层：行为选择 | 写做了什么/没做什么 | "他转身走了，没有回头" |
| 第四层：环境映射 | 用环境暗示情感 | "窗外的雨下得更大了" |

越克制的表达越有力。你不需要写"他很难过"，你只需要写"他在雨里站了很久，后来他回家了，发现忘了买烟，又出门了"。

### 特征六：完美对称

AI特别喜欢写出整齐的排比句、对仗工整的段落。真实的人类文字不会这么"整齐"。

```
AI味：
  "他有勇气，却没有智慧；有力量，却没有方向；
   有热情，却没有坚持。"

人味：
  "他很勇敢。但勇敢有什么用呢？
   他冲上去了，然后呢？然后就没有然后了。
   他连第二步该往哪走都不知道。"
```

**替代技法**：让句子"不完美"——有跑题、有重复、有自我修正、有突然的中断。人说话（和思考）从来不是对仗工整的。

### 特征七：万能比喻

```
AI味：
  "她的笑容像春风一样温暖"
  "他的眼神像利剑一样锐利"
  "夜色像一张黑色的大网笼罩了大地"

人味：
  "她笑起来嘴角往左边歪，像小时候偷吃东西被抓到的样子"
  "他盯着你看的时候你会觉得自己衣服没穿好"
  "天黑了。那种黑法，走路会撞到树上的那种黑"
```

**替代技法**：比喻必须来自角色自己的生活经验和认知范围。
- 一个农村少年不会说"像钻石一样闪耀"，他会说"像露水落在稻叶上"
- 一个程序员不会说"命运的齿轮开始转动"，他会说"感觉像递归调用没设终止条件"
- 一个修仙者会用修炼中的概念来类比

## 二、各题材的语言风格指南

### 2.1 硬科幻：冷叙事

核心原则：**越残酷越冷静**。

| 场景 | 错误做法 | 正确做法 |
|------|---------|---------|
| 大规模死亡 | 渲染恐惧与悲伤 | 用精确数据和时间标记 |
| 暴力场景 | 堆砌血腥细节 | 临床式的准确描写 |
| 文明毁灭 | 大段抒情感叹 | 用物理过程替代情感过程 |
| 关键选择 | 长篇心理独白 | 只写行动，不写思考 |

示例对比：
```
渲染式（不推荐）：
  "舰队的官兵们陷入了巨大的恐惧之中，他们无法相信
   眼前发生的一切，绝望的哭喊声响彻太空……"

冷叙事式（推荐）：
  "水滴用了一分钟十八秒飞完了二千公里的路程，
   贯穿了联合舰队矩形阵列第一队列中的一百艘战舰。"
```

**诗意刺穿**：在通篇冷硬中偶尔嵌入一句柔软——效果放大十倍：
- "她那春藤般的手臂不时轻挥一下，仿佛拂去落在身上的雨滴"
- "人类文明的两粒种子继续向星海深处飘去"
- 使用频率：一个高潮段落最多一到两处，多了就失效

**极端尺度对比**：
```
微观              ↔    宏观
一只蚂蚁在墓碑爬行  ↔    宇宙文明公理的诞生
一个女人的手指      ↔    整个文明的灭亡开关
一滴水的形状        ↔    毁灭两千艘战舰的武器
```

### 2.2 都市奇幻：热叙事

核心原则：**幽默包裹残酷，笑声最密处插刀**。

```
"糖刀"叙事法：
  密集笑点 → 密集笑点 → 密集笑点 → 突然一刀

情绪曲线：
  ↗ 轻松 ↗ 更轻松 ↗ 达到巅峰 ↘↘↘ 急转直下
```

**第一人称幽默感**——内心独白的三个层次：
1. **吐槽层**：对眼前情况的即时反应（搞笑）
2. **真情层**：在吐槽中不经意流露的真实感受（一闪而过）
3. **哲思层**：在极端状态下的人生感悟（简短尖锐）

**比喻的"降维打击"**——用日常意象描写超自然场景：

| 不要这样写 | 要这样写 |
|-----------|---------|
| "龙王散发出惊天动地的威压" | "他们像老朋友那样紧紧相拥，却没法造成任何伤害" |
| "战斗异常激烈" | "双方这么拼微操，快比得上职业选手了" |
| "他感到极度悲伤" | "路明非忽然觉得难过得想哭" |

**对话个性化**：遮住角色名字，仅凭对话就能分辨是谁在说话。对白节奏法则：
- 最重要的那句话应该是最短的
- 搞笑对话越长越好（累积效果），深情对话越短越好
- 角色间的"节奏同步率"体现亲密度

**十二种日常幽默技法**：
1. 错位吐槽：严肃场景中发出不严肃的感慨
2. 伪学术论证：用严肃逻辑推导荒谬结论
3. 降维比喻：用低级事物比喻高级场景
4. 文化碰撞：不同背景角色对同一件事的不同理解
5. 尊严守卫战：角色丢脸后拼命维护最后一点尊严
6. 叙述者调侃：旁白吐槽角色的行为
7. 预期违反：建立严肃预期，用荒诞方式满足
8. 连锁灾难：小失误引发越来越离谱的连锁反应
9. 反差萌：强大角色表现出意外弱点
10. 对话乒乓：两人快速接梗，节奏越来越快
11. 自知之明：角色精准预判自己的惨状并坦然接受
12. 史诗感的日常化：用打游戏、吃快餐等日常行为处理史诗级事件

### 2.3 玄幻修仙：古雅叙事

核心原则：**半文半白，渲染与留白交替**。

```
不要太文（堆砌辞藻）：
  ✗ "天穹苍茫，万里无云，朝霞漫天，金乌东升"

不要太白（缺乏韵味）：
  ✗ "天亮了，太阳出来了，他站起来走了"

要这样（有节奏感、有画面感、但不晦涩）：
  ✓ "苍穹无限，斗转星移，天地一片静默，只有风声，幽幽地吹过。"
```

半文半白的分配：
- 描景用偏古典的语言（营造仙侠氛围）
- 叙事用偏白话的语言（保证可读性）
- 对话用口语化的语言（突出角色个性）
- 内心独白用最朴素的语言（越简单越打动人）

**"留白"与"渲染"的交替**：

```
渲染（用于场景和战斗）：
  浓墨重彩的环境描写
  "白色的寒气如轻烟一般飘着，看去渐渐有些朦胧起来，
   像是做了太久的梦，在梦幻之中若隐若现的影子。"

留白（用于情感高潮）：
  最少的文字，最大的冲击
  "她笑了，咬了咬嘴唇，站了起来，
   最后看了一眼沉睡的男人，转过身走去。"
```

核心原则：越是重要的情感时刻，文字越要克制。

**环境描写即情感隐喻**：

| 环境 | 情感隐喻 |
|------|----------|
| 青竹/翠竹 | 师门记忆，纯真年少 |
| 薄雾/云海 | 迷茫、未知 |
| 暴雨/雷电 | 内心激荡、命运转折 |
| 落日/黄昏 | 离别、无可挽回 |
| 夜空/星辰 | 孤独、永恒、命运无情 |
| 废墟/荒草 | 回忆、物是人非 |
| 冰雪/寒冰 | 封存的感情、沉睡的希望 |

高级用法：同一个场景在不同时间出现，情感含义完全不同。

**法术描写的意境化**：
```
不要这样写：
  "他施展了一个火球术，火球飞向敌人，敌人闪开了。"

要这样写：
  "赤红之光，掠过天际，直插进云雾之中。
   初时云雾翻涌，纷纷退让，
   随后从四面八方围了过来，
   将他的身影渐渐淹没不见了。"
```

## 三、战斗描写通用技法

### 3.1 势能积蓄法

战斗的震撼力不来自描写本身，而来自战前的铺垫：

```
铺垫量 × 角色情感重量 = 战斗冲击力

具体操作：
1. 让对手的强大在战前被充分展示（其他强者在他面前败北）
2. 让主角的弱势被充分强调（所有人都不看好）
3. 让赌注不只是胜负（输了要失去珍贵的东西）
4. 然后才开始打——此时紧张感已经拉满
```

### 3.2 战斗描写的黄金比例

- 30% 动作本身
- 30% 角色的心理/判断/回忆
- 20% 旁观者的反应/解说
- 20% 环境变化/氛围渲染

**核心：战斗写的不是"打架"，而是"抉择"。**

### 3.3 "电影镜头"法

```
远景（环境描写）→ 中景（对峙/对话）→ 近景（技术细节）→ 特写（表情/瞳孔/血滴）
```

### 3.4 Boss战的情感高度设计

```
小Boss → 考验技巧和勇气
中Boss → 考验信念和选择
大Boss → 考验与Boss之间的情感关系
终极Boss → 考验"愿意为此放弃什么"
```

最震撼的战斗不是最炫的特效，而是主角刺出那一刀时说的那句话。

## 四、文献体叙事（科幻特有）

在主叙事中穿插"非小说"文本，制造真实感和史诗感：

可用形式：
- 历史解密文件（含删节和批示）
- 法庭审判记录（对话体）
- 军事通信记录（含层级和编号）
- 学术论文摘要
- 未来史书节选（"后来人们才知道"式预叙）
- 时间线年表（作为附录）

使用原则：文献体不是装饰，而是叙事工具——信息密度远高于正常叙事，适合快速交代大跨度背景变化。

## 五、AI腔快速扫描模式（章节写完后执行）

以下 7 种模式是 AI 生成文字的高频特征，写完一章后逐条用全文搜索（Ctrl+F）检查，命中即需修改。

### 模式1：「那种」单行堆砌

**检测方法**：搜索「那种」，如果同一行出现 ≥ 4 次，说明陷入了 AI 式的嵌套描述

```
❌ "那是那种只有那种极度疲惫的人才会感受到的那种空洞"
✓ 拆开写：描述具体的疲惫行为，而非层层套娃
```

### 模式2：空洞确认句「是真实的，是好的」

**检测方法**：搜索「是真实的」「是好的」

```
❌ "那一切是真实的，是好的，是值得的"
✓ 用具体事件/动作说明"值得"，不要用抽象断言收尾
```

### 模式3：虚指确认句「那件事，是真实的」

**检测方法**：搜索「那件事」+「真实」

```
❌ "那件事，是真实的。它发生过。"
✓ 直接写发生了什么，不需要反复强调真实性
```

### 模式4：独立感悟句「那是好的。」

**检测方法**：搜索「那是好的」「这是好的」

```
❌ 段落结尾单独一句"那是好的。"（AI常用的哲理收尾）
✓ 删除或改写为具体动作/反应，让读者自己感受
```

### 模式5：三重嵌套「那种X是那种Y的那种Z」

**检测方法**：搜索「那种」，找出含 3 个以上「那种」的句子

```
❌ "那种感觉是那种你明知道不对却还是那种控制不住的那种冲动"
✓ 直接写冲动的具体表现（手抖、脚步加快、开口之前停了一下）
```

### 模式6：空洞存在句「那件事就在那里了」

**检测方法**：搜索「就在那里」「就这样了」「就是这样」（作为段落结尾时）

```
❌ "那件事就在那里了。它不会消失。"（无意义的存在确认）
✓ 写它"在那里"对角色造成了什么影响
```

### 模式7：高频词窗口重复

**检测方法**：在任意连续 4 行内，用肉眼或搜索找出重复 ≥ 5 次的同一词语（2–6字）

```
❌ 同一词（如"黑暗""沉默""目光"）在相邻段落反复出现
✓ 换近义词、换角度描写，或直接删去冗余描写
```

### 快速执行清单

```
[ ] 搜索「那种」——单行≥4次？三重嵌套？
[ ] 搜索「是真实的」「是好的」「那是好的」——出现即审查
[ ] 搜索「那件事」——是否跟着空洞断言？
[ ] 搜索「就在那里」「就这样了」——段落结尾是否空洞？
[ ] 通读全章，肉眼扫描高频词——相邻段落同词≥5次？
```

## 六、平台AI检测技术指标与破解方案

> 来源：《文学平台为什么能够判定小说为AI创作？》（百家号，2025-04-23）
> AI文本识别准确率可达90%以上，本节针对各检测维度给出写作层面的应对策略。

### 6.1 熵值检测——打破节奏均匀性

**平台检测原理**：
- 人类写作思维跳跃，熵值波动范围为 0.8–1.2
- AI文本熵值过于平稳，通常维持在 0.95±0.05
- 工具：GLTR（哈佛开发）通过颜色标记词汇预测概率

**写作应对策略**：

```
❌ 均匀的段落节奏（每段3-5行，每句15-20字，推理一路到底）

✓ 主动制造熵值波动：
  · 用极短句打断长段：推理推到关键处，突然一行"他停下来。"
  · 无预兆的话题跳跃：正在分析数据，忽然写他注意到窗外一只鸟
  · 段落长度刻意失衡：一段200字的技术分析，紧接一行20字的感受
  · 在高密度信息段后插入一个完全无逻辑的感官细节
```

**具体操作**：每写完一个连续推理/分析段落（超过200字），必须插入一处"非理性打断"——身体感受、环境细节、无关联想，任选一种。

### 6.2 「完美性」悖论——主动制造人类痕迹

**平台检测原理**：
- AI标点规范率98%+，人类作家约85%
- AI每千字重复词率<0.3%，人类平均1.2%
- AI情感曲线呈标准正弦波（LIWC分析）

**写作应对策略**：

```
❌ 每章情感弧度工整：铺垫→高潮→余韵，节拍均匀

✓ 打破「完美性」的四个方法：

1. 重复词刻意保留
   人类写作会反复用同一个词表达执念——不要全部换成近义词
   "他等。他还在等。等到……" 这种重复是人类腔，不是AI腔

2. 标点不规范化
   偶尔省略逗号，让句子连在一起喘不过气
   偶尔用破折号打断句子——像说话说到一半突然想到别的——再接回来
   问号后不一定要回答，留着

3. 情感曲线故意错位
   不要让情绪随情节同步上升——高潮处角色反而感觉麻木
   低谷处突然冒出一个荒诞的、不合时宜的想法
   悲剧发生后，下一句写他饿了

4. 逻辑不闭合（有意留白）
   人类有「情节漏洞」：不是所有问题都要解释，不是所有伏笔都要收
   让读者带着某个疑问离开本章——不要在章末给出完整答案
```

### 6.3 隐喻创新度——从数据库重组到跳跃性联想

**平台检测原理**：
- AI的隐喻来自训练数据库的模式重组（"像利剑""如春风""宛若星辰"）
- 人类的隐喻来自个人经验的跳跃性联想，往往奇怪、具体、不可预测

**写作应对策略**：

```
❌ 通用比喻库（高AI风险）：
  "像一把利剑刺穿黑暗"
  "宛如晨曦般温暖"
  "如山岳般沉重"
  "像钢铁般的意志"

✓ 角色专属比喻（按职业/经历/年龄定制）：

  军人视角：
    不说"心很沉"，说"像弹药箱压在胸口，搬不动也放不下"
    不说"很疲惫"，说"脑子里的地图已经记不住第几条备用路线了"

  科学家视角：
    不说"感到迷茫"，说"像递归调用没设终止条件"
    不说"找到了方向"，说"第一次在噪声里看见了那个峰值"

  修仙者视角：
    不说"很痛苦"，说"像经脉里走了条错路的灵气，烧着往回找出口"
    不说"很孤独"，说"像散修，没有宗门，连气感都要自己摸索"
```

**核心原则**：写比喻前先问——这个角色的人生里，有什么东西长得像这种感觉？

### 6.4 人物弧光——渐进演变 vs 突变式成长

**平台检测原理**：
- 人类叙事中人物弧光呈「渐进演变」：小事件积累→认知松动→某个临界点→转变
- AI叙事中人物弧光呈「突变式成长」：遇到挑战→克服→获得领悟（模板化）

**写作应对策略**：

```
❌ 突变式（AI高风险）：
  "经历了这一战，他终于明白了什么是真正的责任。"
  "那一刻，她蜕变了。"

✓ 渐进演变写法：

  第一步：埋下「松动迹象」——比转变早3-5章
    角色还没变，但有一个细节说明旧信念开始动摇
    （他这次没有立刻说出那句口头禅——他自己都没注意到）

  第二步：「半步」转变——不要一次到位
    不是"他终于理解了"，而是"他第一次没有立刻反驳"
    不是"她放下了执念"，而是"她把那件东西放到了更难看见的地方"

  第三步：「反复」——转变后的倒退
    已经成长了的角色，在压力下会短暂退回旧模式
    这个倒退才是人味的核心：没有人是线性成长的

  第四步：用行为而非感悟收尾
    不写"他终于懂了"——写他这次做了一个和以前不同的选择
    让读者自己说出那句"他变了"
```

### 6.5 时间戳特征——模拟人类创作节律

**平台检测原理**：
- 人类写作有「创作指纹」：输入速度波动（每分钟5-60字），修改痕迹（约23%内容会重构）
- AI文本显示「瞬时生成」特征（如万字内容提交间隔<3分钟）
- 危险信号：夜间连续创作8小时无停顿，复制粘贴频率异常

**写作应对策略**（针对内容层面）：

```
模拟「修改痕迹」的写作风格：

1. 自我修正句式
   "他感到愤怒——不对，不是愤怒，是一种比愤怒更冷的东西。"
   "她想说谢谢，最后说出来的是'你走吧'。"
   这种「说出口的和想说的不一样」，是人类写作的高频特征

2. 叙述者视角的「犹豫」
   "他在那里站了很久。大概是两分钟，也可能更长。"
   "她应该是哭了——林昊没敢回头看。"
   不确定性的语气标志着人类叙事者

3. 「未完成」的细节
   不要把所有细节写完整——留一个说了一半的动作，一句没说完的话
   "他开口，又关上了。"（不写他想说什么）
   "她把那封信——最后还是放回去了。"（读者不知道信里写了什么）
```

### 6.6 语义网络——从「网状均匀」到「树状分形」

**平台检测原理**：
- 人类文本语义关联呈「树状分形结构」：一个核心主题生长出非对称的枝干
- AI文本语义关联呈「网状均匀分布」：所有主题的权重趋于平均，没有真正的核心

**写作应对策略**：

```
❌ 网状均匀（AI风险）：
  每个章节都均匀推进多条线索
  每个人物都得到等量的心理描写
  每个情节都解释得同样清楚

✓ 树状分形（人类叙事）：
  确立本章「唯一核心」——其他所有内容服务于这一个点
  主角的内心戏比配角厚10倍——不对称是正常的
  某些情节刻意写得简略，某些细节刻意写得过于详细
  允许某条线索「消失」几章，让读者以为忘了——然后突然回来
```

### 六类检测指标快速自检表

写完一章后，针对平台检测维度逐条确认：

```
[ ] 熵值：本章有没有至少3处「非理性打断」（短句/跳跃/无关细节）？
[ ] 完美性：是否保留了至少1处刻意的重复词或不规范标点？
[ ] 情感曲线：情绪是否在某处与情节「错位」而非同步？
[ ] 隐喻：本章所有比喻是否都来自角色的具体经验，而非通用意象？
[ ] 人物弧光：人物若有变化，是否经历了「倒退」而非线性成长？
[ ] 叙事核心：本章是否有一个明确的「最重量的点」，其他一切都比它轻？
[ ] 留白：是否有至少1处「未完成」的细节或未解答的问题？
```
