# 人物档案模板

> 为每个重要角色建档，随故事推进持续更新。

---

## 主要角色档案

```
### [角色姓名]

【基础信息】
  全名：
  常用称呼：___、___、___（列出所有在正文中使用过的称呼）
  年龄：
  性别：
  身份/职业：

【外貌特征】（固定描写，全书保持一致）
  体型：
  面部特征：
  标志性外貌：（如伤疤、发色、特殊装束等）
  常穿服饰：

【性格核心】
  核心执念：
  最大的优点：
  最大的弱点：
  口头禅/说话习惯：
  处于压力下的行为模式：

【说话风格】（用于对话一致性）
  用词偏好：（书面/口语/古典/粗俗/学术...）
  语气特点：（果断/犹豫/调侃/冷淡...）
  独特习惯：（爱用某些词、某种句式、某种停顿方式）
  测试句：写一句只有这个角色会说的话→「___」

【能力/实力】
  当前等级/境界：
  标志性能力/招式：
  装备/法宝：
  弱点/限制：

【人物弧线】
  起点状态：
  当前状态：（随故事更新）
  预计终点：
  关键转变事件：
    1. 第___章：___
    2. 第___章：___
    3. ...

【人物关系】
  [角色B]：关系类型___，关键事件___，当前状态___
  [角色C]：关系类型___，关键事件___，当前状态___
  ...

【重要经历时间线】（按故事内时间排序）
  第___章：___
  第___章：___
  ...

【当前章节状态】（每章更新）
  位置：
  心理：
  最近发生的重要事件：
  目前知道/不知道的关键信息：
```
