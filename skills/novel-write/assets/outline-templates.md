# 大纲模板

> 总纲→卷纲→章纲，逐层填写。

---

## 总纲模板

```
【作品名称】：
【一句话概括】：
【核心矛盾】：___vs___
【世界观锚点】：
【主角定义】：[人名]在[困境]面前选择了[选择]，代价是[代价]
【情感锚点】：读者读完后应感到___
【起点】：
【终点】：
【关键转折】：
  转折1（约第___章）：
  转折2（约第___章）：
  转折3（约第___章）：
  转折4（约第___章）：
  转折5（约第___章）：
【主线】：
【副线1】：
【副线2】：
【世界观揭示计划】：
  第一层（第___章揭示）：
  第二层（第___章揭示）：
  第三层（第___章揭示）：
  第四层（第___章揭示）：
```

---

## 卷纲模板

```
【卷序号/卷名】：
【卷字数预算】：___万字（约___章）
【卷核心事件】：本卷发生的最重要的一件事
【卷情感基调】：
【卷起始状态】：主角在本卷开始时___
【卷结束状态】：主角在本卷结束时___
【本卷新角色】：
  - [角色名]：[身份]，[与主角的关系]
【本卷揭示】：世界观的第___层在本卷揭开，内容是___
【本卷核心战斗/冲突】：
【本卷情感线推进】：
【本卷伏笔】：
  - 埋入：___
  - 回收：___
【下卷钩子】：
【自检】：
  □ 有独立的核心冲突？
  □ 至少一个角色发生明显变化？
  □ 世界观揭示前进了一层？
  □ 有自己的高潮段落？
  □ 结尾有钩子？
```

## 章纲模板

```

【章节标题】：（可选）
【POV（视角人物）】：
【本章目标】：推进___线索，完成___
【预计字数】：___字

【场景列表】：
  场景1：
    地点：___
    在场人物：___
    发生什么：___
    
  场景2：
    地点：___
    在场人物：___
    发生什么：___

  场景3：
    ...

【本章伏笔】：
  埋入：___
  回收：___

【章末钩子】：
  类型：[ ] 悬念型 [ ] 反转型 [ ] 情绪型
  内容：___

【与前章衔接】：
  上章结尾状态：___
  本章开头需要衔接：___

【注意事项】：
  - ___
```
