# 章节总结模板

> 每写完一章，必须填写此模板。这是防止章节不连贯的核心机制。

---

```
=== 第___章「______」总结 ===
写作日期：____-__-__

【故事时间】
  本章时间范围：从___到___
  相对时间：距离故事开始已过___
  当前是故事中的哪个季节/时段：___

【情节推进】（3-5句话概括核心事件）
  1.
  2.
  3.
  4.
  5.

【人物状态更新】

  [角色A]：
    - 当前位置：
    - 心理状态：
    - 关键变化：
    - 与其他角色关系变化：
    - 当前知道什么/不知道什么：

  [角色B]：
    - 当前位置：
    - 心理状态：
    - 关键变化：
    - 与其他角色关系变化：
    - 当前知道什么/不知道什么：

  [角色C]：
    - ...

【伏笔状态】

  新埋伏笔：
    - [伏笔ID-___] ___（预计在第___章回收）

  已回收伏笔：
    - [伏笔ID-___] ___（回收方式：___）

  仍在等待的伏笔（从之前章节继承）：
    - [伏笔ID-___] ___（当前状态：___）

【世界观揭示】
  本章揭示了什么新信息：
  读者现在对世界的理解到了第___层
  本章是否引入了新的设定规则：

【重要物品/道具】
  新出现：
  状态变化：（如法宝受损、药品用尽、关键道具转手等）

【下章衔接要点】
  本章结尾状态：
  下章开头需要衔接：
  注意事项：

【自查清单】
  □ 人物称呼是否与前文一致？
  □ 时间线是否连贯？（与上一章的时间间隔合理吗？）
  □ 空间位置是否合理？（角色怎么到达当前位置的？）
  □ 人物性格表现是否一致？（有无无理由的OOC？）
  □ 已建立的设定是否被违反？
  □ 对话风格是否与角色一致？
  □ 上一章的章末钩子是否在本章得到了回应？
  □ 本章是否推进了至少一条线索？
  □ 本章的节奏是否有起伏？（不能全平或全紧）
  □ 是否违反了防AI化七大禁令？
```
