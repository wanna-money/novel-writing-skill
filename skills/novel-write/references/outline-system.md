# 大纲体系详解

> 总纲→卷纲→章纲，逐层细化——大纲是小说的骨架，每一根骨头都要"可视化"。

---

## 一、篇幅规范

| 维度 | 短篇（1-5万字） | 中篇（5-20万字） | 长篇（20万字以上） |
|------|----------------|-----------------|-------------------|
| 核心线索 | 1条主线 | 1主线+1副线 | 1主线+2-4副线 |
| 主要人物 | 2-4人 | 5-10人 | 10-30人 |
| 世界观层次 | 1-2层 | 2-3层 | 3-5层 |
| 时间跨度 | 数天到数月 | 数月到数年 | 数年到数百年 |
| 章节数 | 3-10章 | 15-40章 | 50章以上，可分卷 |
| 单章字数 | 3000-5000字 | 3000-6000字 | 2000-5000字 |
| 大纲层次 | 总纲+章纲 | 总纲+段纲+章纲 | 总纲+卷纲+段纲+章纲 |

---

## 二、大纲层次结构

### 层次一：总纲（所有篇幅必写）

总纲是整部小说的"灵魂文档"。一份合格的总纲回答七个核心问题：

```
1. 一句话概括：这是一个关于什么的故事？
   → 不是情节概括，而是主题概括
   → 示例："一个凡人在天道无情的世界里，用痴情证明人心有光"
   → 示例："黑暗森林中，人类用善良换来的不是救赎而是毁灭"
   
2. 核心矛盾：故事的根本冲突是什么？
   → 必须是无解的两难，不能有标准答案
   → 示例："生存需要放弃道德 vs 保持道德可能导致灭亡"
   
3. 世界观锚点：这个世界最根本的一条规则是什么？
   → 一条就够，多了就散
   
4. 主角定义：主角是谁？他在核心矛盾面前会做什么选择？
   → 人物=立场+选择+代价
   
5. 情感锚点：读者读完后应该产生什么感受？
   → 这个感受决定语言风格和节奏选择
   
6. 起点与终点：故事从哪里开始，到哪里结束？
   → 落差越大越有力量，最好终点呼应起点
   
7. 三到五个关键转折：故事中最重要的转折点
   → 每个转折都应改变读者对故事的理解
```

### 层次二：卷纲（中篇以上必写）

每一卷/每一大段落的独立规划：

```
卷名：
卷核心事件：本卷发生的最重要的一件事
卷情感基调：本卷给读者的主要感受
卷起始状态：主角在本卷开始时的处境/心态
卷结束状态：主角在本卷结束时的处境/心态
本卷新角色：哪些重要角色在本卷登场？
本卷揭示：世界观的哪一层在本卷被揭开？
下卷钩子：本卷结尾留下什么悬念？
字数预算：本卷预计多少字？
```

每卷必须满足的条件：
1. 有独立的核心冲突（不能只是过渡）
2. 至少一个主要角色发生明显变化
3. 世界观揭示至少前进一层
4. 有自己的高潮段落
5. 结尾留有钩子

### 层次三：章纲（所有篇幅必写）

每一章的写作蓝图：

```
章节编号：
章节标题：（可选，修仙/奇幻常用章回体标题）
POV（视角人物）：
本章目标：推进哪条线索？完成什么任务？
场景列表：
  场景1：[地点] [在场人物] [发生什么]
  场景2：...
本章伏笔：
  埋入：___
  回收：___
章末钩子：用什么方式让读者想翻下一页？
预计字数：
注意事项：（与前后章的衔接要点）
```

## 三、大纲撰写的防AI化原则

写大纲时最容易掉进"AI腔"的陷阱。

**禁止出现的大纲句式**：

| 禁止 | 替换为 |
|------|--------|
| "主角逐渐成长为……" | 列出具体的成长转折事件 |
| "经历了重重考验……" | 列出具体是哪几个考验 |
| "最终战胜了黑暗力量……" | 写出具体的战斗方式和代价 |
| "收获了友情和爱情……" | 写出具体的人物关系变化 |
| "深刻地认识到……" | 写出通过什么事件、什么细节认识到 |
| "一系列冒险之后……" | 列出每一段冒险的具体内容 |

**大纲必须具体到"可视化"**：

```
不合格：
  "第三章：主角在危机中展现勇气，获得同伴认可"

合格：
  "第三章：暴雨夜，山洪冲毁了通往镇子的唯一一座桥。
   张小凡背着受伤的田灵儿，踩着没过膝盖的泥水走了三个时辰。
   到镇上时，田灵儿已经昏过去了，他的脚掌被石头割得血肉模糊。
   宋大仁在门口看到他时，第一次没有嘲笑他。"
```

## 四、短篇/中篇的特殊考量

### 短篇三铁律

1. **一事一议**：只讲一个核心事件，只传递一个核心感受
2. **结尾即灵魂**：短篇的价值80%在结尾（反转/余韵/回环）
3. **每一个字都必须有用**：删掉任何一段后故事仍成立，说明那段多余

### 中篇的双线结构

```
主线：核心事件推进（占70%篇幅）
副线：人物内心变化（占30%篇幅）
两条线在高潮处汇合

节奏公式：
  铺垫（20%）→ 加速（20%）→ 急转（10%）→ 高潮（30%）→ 余韵（20%）
```

## 五、各题材的节奏模板

### 科幻长篇节奏：长蓄短放

核心公式：铺垫时间 : 爆发时间 ≥ 10:1

```
慢节奏区（数千字至数万字）：
  - 科学概念逐步引入
  - 人物日常与心理建设
  - 安全感/希望感营造
  ↓
爆发点（数百字至数千字）：
  - 毁灭性事件瞬间降临
  - 所有铺垫在这一刻兑现
  - 越冷静的语言，越强烈的冲击
```

关键：安全感构建是为了摧毁它。安全感越强，摧毁时的冲击越大。

### 都市奇幻长篇节奏："呼吸感"

```
标准节奏模板（每卷）：
  开篇钩子（1章）：一个悬念/冲击打开全卷
  → 日常蓄力（2-3章）：角色互动、情感铺垫
  → 第一次加速（1-2章）：小冲突爆发
  → 短暂喘息（1章）：搞笑日常/温馨时刻
  → 主冲突（3-5章）：大战/大揭秘/大转折
  → 余韵（1-2章）：情感余波，设置下卷钩子
```

关键：日常段落的质量决定高潮段落的冲击力。

### 修仙长篇节奏："上山-下山"循环

```
上山（修炼期）：学习新功法、同门互动、铺垫伏笔
  ↓
下山（历练期）：遭遇新敌人、运用新能力、获得新领悟
  ↓
回山（沉淀期）：消化经历、实力提升、人际关系变化
```

每一次循环，主角的力量和认知都应有质的飞跃。

### 修仙章节的古典结构

```
章节结构模板：
  起：接续上文，建立本章情境（300-500字）
  承：推进情节，展开冲突（主体部分）
  转：出现意外/反转/新信息（高潮点）
  合：留下悬念或余韵（100-300字）

章末两种写法：
  悬念型："只是他不知道，一个巨大的危险正在向他逼近。"
  余韵型："少年在寂静的黑暗中，低低地、不为人知地叹息。"
```
