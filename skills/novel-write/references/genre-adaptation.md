## 二、各题材的世界观速建指南

### 硬科幻

```
起手式：选一条科学原理
推演式：如果整个宇宙遵守这条规则→文明如何行动→理性最优解是什么
矛盾点：理性最优解与人类道德直觉的冲突
恐怖来源：层层递进——存在威胁→结构威胁→存在性威胁→意义威胁
```

### 都市奇幻

```
起手式：在现实世界选一个裂缝
推演式：裂缝中有什么→为什么没被发现→裂缝在扩大
矛盾点：两个世界注定要碰撞
恐怖来源：考古式深度——地表→中间→深层→底层
```

### 玄幻修仙

```
起手式：选一条天道法则
推演式：天道→修炼体系→门派社会→正邪分野
矛盾点：逆天需代价，顺天失自我
恐怖来源：天道的铁律——越强越接近无情
空间设计：凡界→仙门→险境→魔域→上古遗迹→归处
```

### 西式奇幻

```
起手式：选一套神话/信仰体系
推演式：神意→种族格局→力量代价→凡人觉醒
矛盾点：神的秩序vs凡人的自由
恐怖来源：预言的不可逃避
```

### 末世/废土

```
起手式：选一种灾变
推演式：灾变→资源匮乏→社会重组→新规则
矛盾点：生存本能vs人性底线
恐怖来源：最大的敌人不是怪物，是人
```

## 三、各题材的能力体系速建

| 题材 | 力量形式 | 等级体系 | 代价 | 克制机制 |
|------|---------|---------|------|---------|

| 末世 | 变异/科技/求生技能 | 变异等级/装备等级 | 变异副作用/资源稀缺 | 环境限制/人为争夺 |

## 四、各题材的情感线设计

| 题材 | 情感线特点 | 经典模式 |
|------|-----------|---------|
| 硬科幻 | 情感服从于理念，爱情可能被牺牲 | 知己型（罗辑&庄颜）；因理念分裂 |
| 都市奇幻 | 暗恋为主，不可能的爱情 | 三角关系；日常中萌生情感 |
| 玄幻修仙 | 情是修行的一部分，情劫=天劫 | 双女主选择；情是道还是障？ |
| 西式奇幻 | 命运纠缠，跨种族/跨阵营 | 预言中的命定之人；不可逾越的鸿沟 |
| 末世 | 在绝望中互相取暖 | 生死搭档；末世中的信任比爱情更珍贵 |
