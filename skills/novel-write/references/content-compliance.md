# 内容合规规范

> 适用于所有题材、所有篇幅的创作。优先级高于一切写作技法。
> 规则来源：主流网文平台（番茄、起点、晋江等）内容发布规范综合整理。

---

## 一、地名与国家名规范（最高优先级）

### 核心禁止项

任何真实存在的地理信息**一律不得出现**，包括但不限于：

- **国家**：中国、美国、英国、日本、俄罗斯、德国、法国、韩国……
- **城市**：北京、上海、纽约、东京、伦敦、巴黎、首尔……
- **省份/州**：广东、浙江、加利福尼亚……
- **地标**：长城、故宫、自由女神像、埃菲尔铁塔……
- **山川河流**：长江、黄河、珠穆朗玛峰、亚马逊河……
- **街道/区域**：某某路、某某区……
- **影射写法**：「某大国」「东方古国」「南洋群岛的那个岛国」等明显指向真实国家的描述

### 合规替代方案

**通用架空命名法：**

```
国家/政权命名：
  朝代风：炎朝、盛国、乾朝、宁国、苍渊帝国
  现代风：联邦共和国、星洲联盟、北境联邦（无真实对应）
  玄幻风：天域、冥土帝国、虚空联盟

城市命名：
  古风：长岚城、灵渊都、碧落城、玄京
  现代：星港市、云澜区、白雾镇
  奇幻：悬空之城、深渊要塞、霜华港

山川地形命名：
  断天峰、玄渊江、浮云海、幽冥谷
  北境荒原、南域密林、东洲大陆

方位体系（替代真实大洲/地区）：
  东陆 / 西洲 / 北境 / 南域 / 中原 / 异域
```

**当故事背景需要"现代都市"感时：**
- 用架空城市名 + 描述氛围（"一个繁华的滨海城市""北方的工业重镇"）
- 绝不直接写实名，哪怕是小城市

**当故事涉及多国背景时：**
- 提前在世界观文档中建立完整的架空国家体系
- 每个架空国家有独立的文化特征，不要让读者一眼对应出真实国家

## 二、政治与意识形态

### 禁止项

| 类型 | 具体说明 |
|------|---------|
| 丑化政府/政党 | 用虚构政权影射现实政治体制并进行负面描写 |
| 煽动对立 | 挑起民族矛盾、地域歧视、阶级仇恨的情绪化内容 |
| 宣扬分裂 | 任何形式的国家分裂主张（无论以哪个视角呈现） |
| 影射真实人物 | 以"某领导人""某政治家"等方式影射在任或历史政治人物 |
| 争议历史 | 对存在官方定论的历史事件提出颠覆性或美化反面的解读 |

### 注意事项

- **架空政权的批判是允许的**——写虚构独裁帝国的腐败、虚构战争的残酷均可，但不得让读者形成"这写的就是XX国"的清晰对应
- **历史题材**：以真实朝代为背景时（如架空明朝、架空汉代），人物可以有正反立场，但不得对历史定论进行颠覆性美化/丑化

## 三、色情与性描写

### 禁止项

```
明确性行为描写（包括细节暗示极强的半遮半掩写法）
未成年人的任何性暗示（角色年龄未明确时，写作时默认为成年人）
性暴力/性骚扰的过程描写（可以写发生了这件事及其后果）
以性行为换取利益的细节描写（可提及但不得展开）
```

### 合规边界

```
✓ 爱情、暧昧、心理描写
✓ 接吻（不得细写身体描写）
✓ "门帘式"处理：写到床边，下一幕是翌日清晨
✗ 超过"门帘"的任何内容
```

### 常见误区

- **感情戏激烈化**：大量细腻的身体接触描写（手、腰、颈等）叠加心理描写，整体氛围暧昧过度——需削减
- **意识流性幻想**：主角脑中浮现的性幻想场景，同样适用上述规则

## 四、暴力与血腥

### 禁止项

| 类型 | 说明 |
|------|------|
| 猎奇式施暴 | 以"欣赏"视角细描肢解、折磨、虐待过程 |
| 暴力美化 | 将无差别杀戮包装为酷、帅、爽的体验，且无任何代价感 |
| 犯罪手法教程 | 现实可操作的杀人/爆炸/投毒等方法（哪怕包装成小说情节） |
| 性暴力过程 | 见上一节 |

### 合规写法

- **战斗场面**：可以血腥，但重点放在对抗过程、心理博弈、代价（伤亡/损失），而非肉体破坏的观赏性细节
- **死亡描写**：人物死亡可以有重量感，但不得花大量笔墨渲染尸体/伤口细节
- **反派施暴**：可以写反派残忍（通过结果、幸存者反应、环境侧写），不必事无巨细写施暴过程

## 五、宗教与迷信

### 禁止项

```
攻击/丑化任何现实宗教及其信徒
以宗教名义宣扬极端主义（"圣战""殉道"等极端化叙事）
宣传封建迷信为真实有效（现代背景下写"算命百分百准"）
邪教宣传及其仪式美化
```

### 修仙/玄幻题材注意事项

- 体系中的"道""佛""仙"等概念属于**架空修炼体系**，与现实道教/佛教需有明确区隔
- 不得直接使用现实宗教经文、仪式、神明名称并将其包装为"真实有效的修炼法门"
- 可以借鉴宗教文化的**美学与意象**，但不得宣扬宗教教义

## 六、违法犯罪内容

### 禁止项

| 类别 | 禁止内容 |
|------|---------|
| 毒品 | 制造/提炼方法、使用体验美化、贩卖网络构建 |
| 诈骗/赌博 | 具体诈骗话术、赌博必赢技巧 |
| 网络攻击 | 可操作的黑客工具/步骤/漏洞利用方式 |
| 自杀/自伤 | 具体方法描写（可以写人物自杀意念/行为后果，不写操作过程） |
| 枪械管制 | 非法获取/改造枪支的具体方法 |

### 反派使用上述手段的处理原则

- **写后果，不写方法**：反派用毒——写中毒效果，不写如何配毒
- **写氛围，不写教程**：地下赌场场景——写紧张氛围和人性，不写"这种牌法保准赢"

## 七、低质内容规范

### 禁止项

```
重复内容：同一情节、对话、描写在不同章节中复用（超过50字的重复块）
水文堆砌：大量与情节无关的景物描写、心理独白、动作描述（超过全章20%）
无效剧情：整章看完没有任何推进（人物关系/事件/信息量均无变化）
人物OOC：无前因铺垫的性格突变，或为凑情节让角色做出不符合其逻辑的选择
碾压式升级：主角毫无波折地碾压所有对手，无成长弧线，无代价感
```

### 评估标准

每章写完后问自己三个问题：

1. **本章删掉，读者会错过什么？**（如果答案是"什么都不会错过"，说明是水文）
2. **本章的哪个人物发生了变化？**（可以是认知/情感/处境，至少要有一个）
3. **本章结尾比开头多了什么？**（信息/紧张感/期待感，需有净增量）

## 快速合规自检表

在每章写完后，逐条核查：

```
地名检查
[ ] 扫描全文，是否出现任何真实国家名/城市名/地标名？
[ ] 是否有影射真实地名的描述？
→ 全部替换为架空名称

政治检查
[ ] 是否有可能被解读为攻击现实政治体制的内容？
[ ] 是否影射真实政治人物？
→ 修改或删除

性描写检查
[ ] 是否超出"门帘式"处理范围？
[ ] 是否涉及未成年人的任何性暗示？
→ 削减至合规尺度

暴力检查
[ ] 是否以猎奇/观赏性笔法渲染施暴过程？
[ ] 是否包含现实可操作的犯罪手法？
→ 改写为后果视角

质量检查
[ ] 是否存在大段重复内容？
[ ] 是否超过20%的无效描写？
[ ] 本章是否实质推进了故事？
→ 精简或补写有效内容
```
