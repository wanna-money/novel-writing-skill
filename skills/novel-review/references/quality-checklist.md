# 写作自检清单

> 迁移自 novel-write SKILL.md 的「写作自检清单」，novel-review 的 solo 模式和三个审查视角均可引用本清单作为基础检查项。

## 章节级

- [ ] 本章推进了至少一条线索？
- [ ] 章末有翻页钩子？
- [ ] 情感节奏有起伏（不能全平或全紧）？
- [ ] 未违反防AI化七大禁令（见 `skills/novel-deslop/references/anti-ai-writing.md`）？
- [ ] 执行了AI腔快速扫描（`node skills/novel-deslop/scripts/check-ai-patterns.js`）？
- [ ] 章节总结已填写并更新？
- [ ] 通过合规自检（见 `skills/novel-write/references/content-compliance.md`）？

## 卷级

- [ ] 本卷有独立的核心冲突和高潮？
- [ ] 至少一个主要角色发生了明显变化？
- [ ] 世界观揭示前进了至少一层？
- [ ] 所有本卷伏笔已回收或标记为长线？

## 全书级

- [ ] 主角成长弧线完整？
- [ ] 核心矛盾得到充分展示？
- [ ] 所有伏笔已回收？
- [ ] 结尾呼应了开头？
- [ ] 通读后产生了预设的情感效果？
