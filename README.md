# novel-writing-skill

万能小说写作方法论 Skill，覆盖短篇/中篇/长篇，适配玄幻/科幻/修仙/奇幻/末世等主流题材。

参考 MuMuAINovel 项目的工业级网文写作体系，整合《三体》《龙族》《诛仙》等经典作品写作手法。

## 功能

- **六阶段写作流程**：立项定调 → 世界观构建 → 人物矩阵 → 大纲编制 → 章节写作 → 连贯性维护
- **防AI化七大禁令**：保持文字的人味，杜绝空洞形容词、总结式叙事、情感直述等
- **三层大纲体系**：总纲→卷纲→章纲，推荐大纲:正文 = 1:2.5–3
- **伏笔追踪系统**：三级分类管理，自动提示逾期未收的伏笔
- **题材适配**：硬科幻/都市奇幻/玄幻修仙/西式奇幻各有专项语言风格指南
- **多套情感弧模板**：V形/倒V形/W形/阶梯递进/延迟满足/急转共六种

## 使用

当你提出写小说相关的请求时，该 skill 会自动触发：

- "帮我写一篇玄幻短篇"
- "设计这部科幻小说的世界观"
- "我要开始写一部修仙长篇，帮我立项"
- "这章节的节奏不对，帮我修改"
- "追踪第三章的伏笔"

## 六阶段流程概览

| 阶段 | 内容 | 核心产出 |
|------|------|---------|
| 一：立项定调 | 篇幅/题材/核心矛盾/情感目标 | 项目立项文档 |
| 二：世界观构建 | 一条法则推导整个世界 | 世界观备忘录 |
| 三：人物矩阵 | 主角+配角+反派+关系网 | 人物档案 |
| 四：大纲编制 | 三层大纲+八节点结构 | 完整大纲 |
| 五：章节写作 | 防AI化+节奏公式 | 章节正文 |
| 六：连贯性维护 | 伏笔追踪+章节总结 | 维护文档 |
